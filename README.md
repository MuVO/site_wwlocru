# WWLOC

Независимый фронтенд-проект WWLOC на React и Vite. Исходный проект в родительском каталоге не затрагивается.

Сайт автоматически выбирает русский или английский язык по настройкам браузера. Выбор можно изменить переключателем RU/EN; ручная настройка сохраняется в браузере.

## Настройки сборки

Скопируйте `.env.example` в `.env.local` для локальной настройки. В GitHub Actions задайте repository variables `VITE_YANDEX_MAPS_API_KEY` (ключ JavaScript API Яндекс Карт) и `VITE_FEEDBACK_API_URL` (URL Lambda HTTP API). Все переменные с префиксом `VITE_` попадают в клиентскую сборку и не являются секретами; ограничьте ключ карт по HTTP referrer в кабинете Яндекса. Без ключа сайт открывает OpenStreetMap.

## Запуск и проверка

Требуется Node.js с npm.

```sh
npm install
npm run dev
```

Vite запустит сайт по адресу `http://localhost:5173`. Для отображения карты требуется подключение к интернету и доступность JavaScript API Яндекс Карт.

Под картой можно переключаться между Яндекс.Картами и OpenStreetMap и включать слой терминатора (ночная сторона Земли). Для OpenStreetMap отображается обязательная атрибуция участников OSM; загрузка тайлов требует сети.

В поле локатора есть режим измерения расстояния: задайте два локатора, чтобы увидеть их ячейки, соединяющую линию и расстояние между центрами ячеек. Результат можно отображать в километрах или милях.

Ссылки на поиск и измерение сохраняются в URL-хэше: `#MO05QE` открывает поиск локатора, `#MO05QE:KO85BC` — измерение между двумя локаторами. Кнопки в блоке «Поделитесь с друзьями» открывают шаринг в VK, OK, Telegram, WhatsApp, Facebook и MAX; последняя кнопка копирует текущую ссылку.

Запуск тестов и production-сборки:

```sh
npm test
npm run build
npm run preview
```

## Поиск и SEO

Страница включает canonical URL, метаданные Open Graph/Twitter, JSON-LD `WebApplication`, `robots.txt` и `sitemap.xml`. Язык документа и описания страницы синхронизируются с выбранным RU/EN интерфейсом. Хэши `#MO05QE` и `#MO05QE:KO85BC` кодируют состояние поиска/измерения для прямых ссылок и шаринга; отдельными индексируемыми страницами они не являются.

Математика локаторов находится в `src/locatorMath.ts` и работает в браузере без запросов к серверу приложения:

- кодирование и декодирование локаторов IARU/Maidenhead переменной чётной длины (интерфейс принимает до 12 пар символов);
- границы ячейки и её центр;
- расстояние по большому кругу, прямой и обратный азимут;
- расчёт маршрута через несколько точек;
- магнитное склонение и наклонение по модели WMM2025.

WMM2025 опубликована NOAA/NCEI совместно с BGS и предназначена для эпохи 2025.0–2030.0. Вне этого интервала результат модели отмечается в интерфейсе. Значения рассчитываются для центра ячейки локатора.

## Терминология и источники

На сайте под Maidenhead Locator System понимается всемирная система локаторов, принятая рабочей группой IARU Region 1 по VHF в 1980 году. «QTH-локатор» — широко употребительное радиолюбительское название, но исторически так называли также более раннюю систему QRA/QTH Locator. Поэтому эти названия не следует смешивать как названия одной и той же исторической системы. WWL/WWLoc — обозначения локатора, а не самостоятельная система координат.

По актуальному руководству IARU Region 1 локатор имеет переменную чётную длину: пары букв, цифр, букв, цифр и далее повторяются; расширенный пример из руководства — `JN18DU55IX` (10 символов). IARU рекомендует заглавные буквы для записи, при этом программы должны принимать любой регистр и смешанные варианты. Внутри приложения запись нормализуется к верхнему регистру. Из-за ограничений точности чисел с плавающей запятой интерфейс ограничивает ввод 24 символами (12 пар).

- [IARU Region 1 VHF Handbook — раздел The Locator System](https://www.iaru-r1.org/wp-content/uploads/2026/02/VHF_Handbook_V10_03_final.pdf)
- [История системы локаторов, публикация на QRZ.ru (PDF)](https://www.qrz.ru/vhf/qth_h.pdf)
- [ARRL: Grid Squares](https://www.arrl.org/grid-squares)
- [NOAA/NCEI: World Magnetic Model](https://www.ncei.noaa.gov/products/world-magnetic-model)

В тестах проверяются опубликованные NOAA/NCEI контрольные значения WMM2025 и базовые расчёты локаторов и расстояний.

Форма обратной связи использует отдельный AWS Lambda backend из `../wwloc-backend/`, который отправляет сообщения в Telegram. Для включения задайте `VITE_FEEDBACK_API_URL` при сборке сайта.

## Подготовка GitHub Pages

В проекте подготовлен workflow публикации из `dist` и домен `wwloc.ru` в `public/CNAME`. Чтобы включить публикацию, потребуется выбрать **GitHub Pages → GitHub Actions** в настройках репозитория и настроить DNS у регистратора домена. Workflow не запускался, сайт не публиковался.
